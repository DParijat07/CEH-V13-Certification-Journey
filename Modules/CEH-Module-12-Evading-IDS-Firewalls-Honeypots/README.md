# CEH Module 12 – Evading IDS, Firewalls, and Honeypots

## Overview

This repository contains my study notes, practical lab documentation, and TryHackMe writeups for **CEH v13 Module 12 – Evading IDS, Firewalls, and Honeypots**.

This module explores how modern defensive technologies detect malicious activities and how security professionals study common evasion techniques to improve detection capabilities, strengthen security controls, and perform authorized security assessments.

> **Disclaimer:** This repository is created for educational purposes, CEH certification preparation, defensive security learning, and authorized penetration testing only.

---

# Learning Objectives

After completing this module, I will be able to:

- Understand the purpose of Firewalls in network security.
- Differentiate between IDS, IPS, WAF, and Next-Generation Firewalls.
- Understand packet filtering and stateful inspection.
- Learn IDS detection methodologies.
- Understand common traffic obfuscation and evasion concepts.
- Learn about Honeypots and Honeynets.
- Understand how SOC teams detect evasion attempts.
- Perform basic network traffic analysis.
- Apply defensive security best practices.
