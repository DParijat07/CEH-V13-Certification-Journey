# Module 13 – Hacking Web Servers

# Interview Questions

---

# Basic Level

## 1. What is a web server?

A web server is software (and the hardware it runs on) that receives HTTP/HTTPS requests from clients and delivers web pages, files, APIs, or other web resources.

---

## 2. Name three popular web servers.

- Apache HTTP Server
- Microsoft IIS
- Nginx

---

## 3. What is HTTP?

HTTP (Hypertext Transfer Protocol) is an application-layer protocol used for communication between web browsers and web servers.

Default Port: **80**

---

## 4. What is HTTPS?

HTTPS is the secure version of HTTP that uses TLS to encrypt communication.

Default Port: **443**

---

## 5. Why is HTTPS preferred over HTTP?

Because HTTPS provides:

- Confidentiality
- Integrity
- Authentication

---

## 6. Which OSI layer does HTTP operate on?

Application Layer (Layer 7)

---

## 7. What is a client?

A client is a device or application that sends requests to a web server.

Examples:

- Chrome
- Firefox
- Edge

---

## 8. What is a web application?

A web application is software accessed through a web browser that provides interactive functionality over HTTP/HTTPS.

---

## 9. What is a static website?

A website that serves fixed content to all users without server-side processing.

---

## 10. What is a dynamic website?

A website that generates content dynamically using server-side code and databases.

---

## 11. What is Apache?

Apache HTTP Server is an open-source web server widely used on Linux and other operating systems.

---

## 12. What is Microsoft IIS?

IIS (Internet Information Services) is Microsoft's web server platform for Windows Server.

---

## 13. What is Nginx?

Nginx is a high-performance web server commonly used as a reverse proxy and load balancer.

---

## 14. What is a reverse proxy?

A reverse proxy receives client requests and forwards them to backend servers.

Benefits include:

- Security
- Load balancing
- SSL termination
- High availability

---

## 15. What is a load balancer?

A load balancer distributes incoming traffic across multiple servers to improve performance and availability.

---

## 16. What is a Virtual Host?

A Virtual Host allows multiple websites to run on a single web server.

---

## 17. What is DNS?

DNS (Domain Name System) translates domain names into IP addresses.

---

## 18. What are the default ports for HTTP and HTTPS?

HTTP → Port 80

HTTPS → Port 443

---

## 19. What is TLS?

TLS (Transport Layer Security) encrypts communication between clients and servers.

---

## 20. What is an SSL/TLS certificate?

A digital certificate used to authenticate a server and establish encrypted communication.

---

## 21. What is a Certificate Authority (CA)?

A trusted organization that issues and verifies digital certificates.

Examples:

- DigiCert
- Let's Encrypt
- GlobalSign

---

## 22. What is an HTTP request?

A message sent from a client requesting a resource from a web server.

---

## 23. What is an HTTP response?

A message returned by the web server containing the requested resource or status information.

---

## 24. What are HTTP headers?

Headers contain additional information about HTTP requests and responses.

Examples:

- Host
- User-Agent
- Content-Type
- Authorization

---

## 25. What are cookies?

Cookies are small pieces of data stored in the user's browser to support session management, authentication, and user preferences.
