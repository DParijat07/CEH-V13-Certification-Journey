# CEH Module 13 – Hacking Web Servers

## Overview

This module covers web server technologies, architecture, common vulnerabilities, attack techniques, security controls, hardening practices, and detection methods.

The goal is to understand how web servers operate, how they are attacked, and how organizations defend them.

---

## Learning Objectives

- Understand web server architecture
- Learn Apache, IIS, and Nginx basics
- Understand HTTP/HTTPS communication
- Study common web server attacks
- Learn web server enumeration concepts
- Understand server hardening
- Learn defensive best practices
- Practice web server assessment in a lab environment
