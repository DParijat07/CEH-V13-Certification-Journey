# SQL Fundamentals

## Overview

Structured Query Language (**SQL**) is the standard language used to communicate with relational databases. It enables applications to store, retrieve, modify, and manage structured data efficiently.

Nearly every modern web application—including banking systems, e-commerce platforms, healthcare portals, learning management systems, and social media platforms—uses SQL to interact with backend databases.

Understanding SQL fundamentals is essential before studying SQL Injection and database security.

---

# What is a Database?

A **database** is an organized collection of structured data that can be stored, managed, and retrieved efficiently.

Examples of information stored in databases include:

- User accounts
- Customer records
- Orders
- Product information
- Employee details
- Payment transactions
- Medical records

---

# Database Management System (DBMS)

A **Database Management System (DBMS)** is software that manages databases and provides an interface between applications and stored data.

Responsibilities include:

- Data storage
- Data retrieval
- Data modification
- User management
- Security
- Backup and recovery
- Transaction management

---

# Relational Database Management System (RDBMS)

An **RDBMS** stores data in related tables consisting of rows and columns.

Characteristics:

- Table-based structure
- Relationships between tables
- Supports SQL
- Multi-user access
- ACID compliance
- High reliability

Examples:

- MySQL
- PostgreSQL
- MariaDB
- Microsoft SQL Server
- Oracle Database

---

# Common Database Components

## Table

Stores related information.

Example:

| Student_ID | Name | Course |
|------------|------|--------|
| 101 | Alice | CSE |
| 102 | Bob | IT |

---

## Row (Record)

A single entry in a table.

Example:

```
101 | Alice | CSE
```

---

## Column (Field)

A specific attribute of the data.

Examples:

- Name
- Email
- Department
- Salary

---

## Primary Key

A field that uniquely identifies each record.

Characteristics:

- Unique
- Cannot be NULL
- One primary key per table

---

## Foreign Key

A field that links one table to another.

Benefits:

- Maintains relationships
- Improves data integrity
- Reduces duplication

---

# SQL Categories

## Data Definition Language (DDL)

Defines database structure.

Commands:

- CREATE
- ALTER
- DROP
- TRUNCATE

---

## Data Manipulation Language (DML)

Modifies stored data.

Commands:

- INSERT
- UPDATE
- DELETE

---

## Data Query Language (DQL)

Retrieves information.

Command:

- SELECT

---

## Data Control Language (DCL)

Controls permissions.

Commands:

- GRANT
- REVOKE

---

## Transaction Control Language (TCL)

Manages transactions.

Commands:

- COMMIT
- ROLLBACK
- SAVEPOINT

---

# CRUD Operations

Most web applications perform four basic operations.

| Operation | SQL Command |
|-----------|-------------|
| Create | INSERT |
| Read | SELECT |
| Update | UPDATE |
| Delete | DELETE |

# Database Security Principles

A secure database should provide:

- Confidentiality
- Integrity
- Availability
- Authentication
- Authorization
- Accountability

---

# Best Practices

- Use strong authentication
- Apply the Principle of Least Privilege
- Encrypt sensitive information
- Keep database software updated
- Restrict administrative access
- Enable logging and monitoring
- Perform regular backups
- Conduct periodic security assessments

---

# CEH Exam Tips

Remember:

- SQL is the standard language for relational databases.
- RDBMS stores data in related tables.
- CRUD stands for Create, Read, Update, and Delete.
- Primary Keys uniquely identify records.
- Foreign Keys create relationships between tables.
- Databases are valuable targets because they often contain sensitive information.

---

# Key Takeaways

- SQL is the foundation of relational database communication.
- Understanding database structure and SQL concepts is essential before learning SQL Injection.
- Strong database security depends on secure configuration, least privilege, encryption, monitoring, and regular maintenance.
