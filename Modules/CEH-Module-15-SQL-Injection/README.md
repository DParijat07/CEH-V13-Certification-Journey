# CEH Module 15: SQL Injection

## Overview

This repository contains my study notes, practical labs, and documentation for **Module 15: SQL Injection** from the **Certified Ethical Hacker (CEH v13)** curriculum.

SQL Injection (SQLi) is one of the most critical and well-known web application vulnerabilities. It occurs when an application improperly handles user input, allowing attackers to manipulate SQL queries executed by the backend database.

This module covers SQL fundamentals, database architecture, SQL Injection concepts, common attack techniques, secure coding practices, defensive controls, and database security best practices. The focus of this repository is on **learning**, **documentation**, and **defensive security awareness**.

> **Disclaimer**
>
> All practical activities and demonstrations are performed in authorized lab environments such as TryHackMe, DVWA, OWASP Juice Shop, and personal virtual machines. The content is intended solely for cybersecurity education and ethical hacking.

---

# Learning Objectives

After completing this module, I will be able to:

- Understand relational databases and SQL fundamentals.
- Explain how SQL Injection vulnerabilities occur.
- Identify different types of SQL Injection attacks.
- Understand common database technologies.
- Learn secure coding practices to prevent SQL Injection.
- Understand database hardening techniques.
- Map SQL Injection concepts to the MITRE ATT&CK framework.
- Apply SQL Injection knowledge in ethical hacking and VAPT labs.
- Improve defensive security awareness for modern web applications.
