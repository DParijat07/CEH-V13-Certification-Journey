# Wireless Network Fundamentals

## Overview

A **wireless network** enables devices to communicate using **radio frequency (RF)** signals instead of physical cables. Wireless networking provides mobility, flexibility, and scalability, making it the preferred networking technology for homes, businesses, educational institutions, healthcare organizations, and public spaces.

Understanding wireless networking fundamentals is essential before learning wireless security concepts and threat mitigation.

---

# What is a Wireless Local Area Network (WLAN)?

A **Wireless Local Area Network (WLAN)** connects devices within a limited geographical area using Wi-Fi technology.

Common examples include:

- Home Wi-Fi
- Office networks
- University campuses
- Airports
- Hotels
- Coffee shops

---

# Advantages of Wireless Networks

Wireless networking offers several benefits:

- Mobility
- Flexible deployment
- Reduced cabling
- Easy expansion
- Support for mobile devices
- Convenient Internet access

---

# Limitations of Wireless Networks

Wireless networks also have challenges:

- Signal interference
- Limited coverage
- Shared bandwidth
- Environmental obstacles
- Greater exposure to unauthorized access

---

# Wireless Communication

Wireless communication uses **electromagnetic radio waves** to exchange information between devices.

Communication quality depends on:

- Distance
- Signal strength
- Frequency band
- Channel selection
- Physical obstacles
- Interference

---

# IEEE 802.11 Standards

The **IEEE 802.11** family of standards defines how Wi-Fi networks operate.

It specifies:

- Physical layer (PHY)
- MAC layer
- Channel usage
- Wireless communication procedures

---

# Common IEEE 802.11 Standards

| Standard | Frequency | Common Name |
|-----------|-----------|-------------|
| 802.11a | 5 GHz | Wi-Fi |
| 802.11b | 2.4 GHz | Wi-Fi |
| 802.11g | 2.4 GHz | Wi-Fi |
| 802.11n | 2.4 / 5 GHz | Wi-Fi 4 |
| 802.11ac | 5 GHz | Wi-Fi 5 |
| 802.11ax | 2.4 / 5 / 6 GHz | Wi-Fi 6 / 6E |
| 802.11be | 2.4 / 5 / 6 GHz | Wi-Fi 7 |

---

# Wireless Network Architecture

Typical WLAN architecture:

```
Internet
    │
Router
    │
Access Point
    │
~~~~~~~~~~~~~~~~~~
Wireless Clients
```

The Access Point connects wireless devices to the wired network.

---

# Infrastructure Mode

Characteristics:

- Uses an Access Point
- Centralized communication
- Internet connectivity
- Most common deployment model

---

# Ad Hoc Mode

Characteristics:

- Device-to-device communication
- No Access Point required
- Temporary peer-to-peer network
- Limited scalability

---

# SSID

The **Service Set Identifier (SSID)** is the visible name of a wireless network.

Examples:

- Office-WiFi
- HomeNetwork
- GuestWiFi

---

# BSSID

The **Basic Service Set Identifier (BSSID)** uniquely identifies an Access Point.

It is typically derived from the Access Point's MAC address.

---

# ESSID

The **Extended Service Set Identifier (ESSID)** allows multiple Access Points to provide seamless wireless coverage using the same network name.

Common in enterprise environments.

---

# Frequency Bands

## 2.4 GHz

Advantages:

- Longer range
- Better wall penetration

Disadvantages:

- More interference
- Fewer available channels

---

## 5 GHz

Advantages:

- Higher throughput
- Less interference
- More non-overlapping channels

Disadvantages:

- Shorter range
- Reduced wall penetration

---

## 6 GHz

Advantages:

- High bandwidth
- Lower latency
- Reduced congestion

Disadvantages:

- Shorter effective range
- Requires compatible hardware

---

# Wireless Channels

Wireless communication occurs on channels within each frequency band.

Proper channel planning helps:

- Improve performance
- Reduce interference
- Increase reliability

# CEH Exam Tips

Remember:

- IEEE 802.11 defines Wi-Fi standards.
- Infrastructure Mode uses an Access Point.
- Ad Hoc Mode enables peer-to-peer communication.
- SSID identifies a wireless network.
- BSSID uniquely identifies an Access Point.
- Wi-Fi 6 is based on IEEE 802.11ax.
- Wi-Fi 7 is based on IEEE 802.11be.
- 2.4 GHz provides greater range, while 5 GHz generally offers higher performance.
