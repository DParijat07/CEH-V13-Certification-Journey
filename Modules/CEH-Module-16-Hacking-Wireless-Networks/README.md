# CEH Module 16: Hacking Wireless Networks

## Overview

This repository contains my study notes, practical labs, and documentation for **Module 16: Hacking Wireless Networks** from the **Certified Ethical Hacker (CEH v13)** curriculum.

Wireless networks have become an essential part of modern organizations, homes, educational institutions, and public infrastructure. While they provide flexibility and mobility, they also introduce unique security challenges.

This module covers wireless networking fundamentals, IEEE 802.11 standards, Wi-Fi authentication and encryption, common wireless threats, defensive security controls, and wireless network monitoring.

The focus of this repository is on **ethical hacking, defensive security, and authorized security testing**.

> **Disclaimer**
>
> All practical activities are performed in authorized lab environments such as TryHackMe, personal home labs, and intentionally vulnerable systems. The content is intended solely for cybersecurity education and ethical hacking.

---

# Learning Objectives

After completing this module, I will be able to:

- Understand wireless networking fundamentals.
- Explain IEEE 802.11 wireless standards.
- Differentiate wireless authentication and encryption methods.
- Identify common wireless attacks and risks.
- Understand wireless reconnaissance concepts.
- Learn wireless security best practices.
- Explain Wireless IDS/IPS concepts.
- Map wireless attacks to the MITRE ATT&CK framework.
- Apply wireless security concepts in CEH labs and VAPT engagements.
