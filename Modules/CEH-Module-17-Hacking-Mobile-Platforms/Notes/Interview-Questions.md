# Rapid Revision Sheet

Remember:

- Android is Linux-based.
- iOS uses the XNU kernel.
- Every mobile application runs inside a sandbox.
- Secure Boot verifies trusted startup components.
- Verified Boot checks Android system integrity.
- Android Keystore protects cryptographic keys.
- Secure Enclave protects sensitive operations on Apple devices.
- Keychain securely stores passwords and authentication material.
- Google Play Protect scans Android applications.
- Device encryption protects data at rest.
- MFA strengthens authentication.
- VPN protects communication over untrusted networks.
- MDM manages devices.
- EMM manages devices, applications, content, and identities.
- UEM manages all enterprise endpoints.
- MTD detects mobile threats.
- Smishing is phishing through SMS.
- SIM swapping can bypass SMS-based MFA.
- Rooting and jailbreaking weaken built-in security controls.
- SIEM enables centralized monitoring and alerting.

# Interview Tips

When answering mobile security questions:

- Explain concepts clearly before giving examples.
- Differentiate Android and iOS security mechanisms.
- Relate answers to enterprise security controls such as MDM, UEM, MFA, and SIEM.
- Highlight defense-in-depth and Zero Trust principles.
- Emphasize user awareness, regular updates, and continuous monitoring.
- Use structured, practical responses for scenario-based questions.

---

# Key Takeaways

- Mobile platform security combines operating system protections, enterprise management, strong authentication, encryption, continuous monitoring, and user awareness.
- Security professionals should understand both Android and iOS architectures, common mobile threats, and enterprise defense strategies.
- A layered security approach significantly reduces the risk of mobile compromise in organizational environments.
