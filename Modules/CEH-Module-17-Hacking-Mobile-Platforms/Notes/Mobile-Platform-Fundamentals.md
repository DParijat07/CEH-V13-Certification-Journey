# Mobile Platform Fundamentals

## Overview

Mobile platforms have become an essential part of modern computing, enabling users to communicate, access cloud services, perform financial transactions, and manage business operations from virtually anywhere. Because mobile devices store sensitive personal and enterprise information, understanding their architecture and security is critical for cybersecurity professionals.

This document introduces the fundamentals of mobile platforms, mobile operating systems, device architecture, and communication technologies.

---

# What is Mobile Computing?

Mobile computing refers to the use of portable computing devices that communicate over wireless networks while providing access to applications, data, and services.

Common mobile devices include:

- Smartphones
- Tablets
- Smartwatches
- Rugged enterprise devices
- Mobile Point-of-Sale (mPOS) terminals

---

# Characteristics of Mobile Computing

Key characteristics include:

- Portability
- Mobility
- Wireless connectivity
- Cloud integration
- Always-on communication
- Sensor integration
- Location awareness

# Mobile Operating Systems

A Mobile Operating System (Mobile OS) manages hardware resources, applications, security, and user interaction.

The two dominant mobile operating systems are:

- Android
- iOS

Other mobile platforms include:

- HarmonyOS
- KaiOS
- Embedded Linux-based systems

---

# Android Overview

Android is an open-source mobile operating system developed by Google.

Characteristics:

- Linux-based kernel
- Highly customizable
- Large application ecosystem
- Google Play Store
- Used by multiple hardware manufacturers

Common Android device manufacturers include:

- Samsung
- Google
- Xiaomi
- OnePlus
- Motorola
- Nothing

---

# iOS Overview

iOS is Apple's proprietary mobile operating system.

Characteristics:

- Closed ecosystem
- Tight hardware and software integration
- Strong built-in security
- Apple App Store
- Regular security updates

Supported primarily on Apple mobile devices.

# SIM and eSIM

## SIM

A Subscriber Identity Module (SIM) stores subscriber identity information used by cellular networks.

Functions include:

- User identification
- Network authentication
- Subscriber information

---

## eSIM

An Embedded SIM (eSIM) is integrated into the device hardware.

Advantages:

- Remote provisioning
- Multiple carrier profiles
- Greater flexibility
- Reduced hardware requirements

# Key Takeaways

- Mobile devices are powerful computing platforms that require strong security controls.
- Android and iOS dominate the mobile operating system market.
