# Mobile Threats and Attacks

## Overview

Mobile devices have become essential for personal and enterprise use, making them attractive targets for cybercriminals. Smartphones and tablets store sensitive information, provide access to business applications, and are frequently connected to cloud services.

Understanding common mobile threats enables organizations to implement effective security controls and reduce business risk.

---

# Mobile Malware

## Overview

Mobile malware is malicious software designed to compromise smartphones or tablets.

Potential impacts include:

- Data theft
- Privacy violations
- Unauthorized device control
- Financial loss
- Business disruption

### Defensive Controls

- Install applications only from trusted sources
- Keep the operating system updated
- Deploy Mobile Threat Defense (MTD)
- Monitor device behavior
- Educate users about mobile security

---

# Spyware

## Overview

Spyware secretly collects information from a mobile device without the user's knowledge.

Common targets include:

- Messages
- Contacts
- Call history
- Location data
- Browsing activity

### Defensive Controls

- Review application permissions regularly
- Remove unnecessary applications
- Install security updates promptly
- Monitor for unusual device behavior

---

# Ransomware

## Overview

Mobile ransomware attempts to deny access to a device or its data until a ransom is paid.

Potential impacts:

- File encryption
- Device lockout
- Data loss
- Business interruption

### Defensive Controls

- Maintain secure backups
- Keep software updated
- Install applications only from trusted sources
- Use endpoint protection solutions

---

# Banking Trojans

## Overview

Banking trojans target financial applications to steal sensitive information.

Potential impacts:

- Credential theft
- Financial fraud
- Unauthorized transactions
- Identity theft

### Defensive Controls

- Enable Multi-Factor Authentication (MFA)
- Use official banking applications
- Monitor financial accounts
- Keep banking applications updated

---

# Adware

## Overview

Adware displays excessive advertisements and may collect user information.

Potential impacts:

- Reduced device performance
- Privacy concerns
- Poor user experience

### Defensive Controls

- Install trusted applications
- Review requested permissions
- Remove suspicious software

---

# Smishing (SMS Phishing)

## Overview

Smishing is a phishing attack delivered through SMS or messaging applications.

Attackers attempt to convince users to:

- Reveal credentials
- Visit fraudulent websites
- Install malicious applications
- Share sensitive information

### Defensive Controls

- Verify sender identity
- Avoid suspicious links
- Report phishing messages
- Conduct user awareness training

---

# Malicious Applications

## Overview

Malicious applications may appear legitimate while performing unauthorized activities.

Potential risks include:

- Credential theft
- Data collection
- Privacy violations
- Device compromise

### Defensive Controls

- Download applications only from trusted stores
- Verify developer information
- Review application permissions
- Remove unused or suspicious applications

---

# Insecure Wi-Fi Networks

## Overview

Public or poorly secured Wi-Fi networks increase the risk of data interception.

Potential impacts:

- Credential exposure
- Session compromise
- Unauthorized monitoring
- Data leakage

### Defensive Controls

- Use a Virtual Private Network (VPN)
- Prefer HTTPS connections
- Avoid sensitive transactions on public Wi-Fi
- Disable automatic Wi-Fi connections

---

# Bluetooth Threats

## Overview

Bluetooth enables short-range wireless communication between devices.

Security risks include:

- Unauthorized pairing
- Data exposure
- Device discovery abuse

### Defensive Controls

- Disable Bluetooth when not in use
- Pair only with trusted devices
- Keep Bluetooth software updated
- Disable discoverable mode when unnecessary

---

# Near Field Communication (NFC) Risks

## Overview

NFC enables short-range contactless communication.

Potential risks:

- Unauthorized transactions
- Data exposure
- Device misuse

### Defensive Controls

- Disable NFC when not required
- Use trusted payment applications
- Verify payment requests before approval

---

# SIM Swapping

## Overview

SIM swapping occurs when an attacker fraudulently transfers a victim's phone number to another SIM card.

Potential impacts:

- Account takeover
- SMS-based MFA bypass
- Identity theft

### Defensive Controls

- Enable carrier account protection
- Use authentication applications where possible
- Monitor unexpected loss of cellular service
- Contact the mobile carrier immediately if suspicious activity occurs

---

# Rooting and Jailbreaking (Conceptual)

## Rooting (Android)

Rooting removes manufacturer restrictions and grants elevated privileges.

## Jailbreaking (iOS)

Jailbreaking removes Apple's software restrictions.

### Security Risks

- Reduced platform security
- Increased malware exposure
- Unsupported device configurations
- Higher risk of compromise

Organizations commonly prohibit rooted or jailbroken devices from accessing enterprise resources.

---

# Data Leakage

## Overview

Sensitive information may be exposed through:

- Lost or stolen devices
- Misconfigured applications
- Cloud synchronization
- Weak authentication
- User error

### Defensive Controls

- Enable device encryption
- Require strong authentication
- Support remote lock and remote wipe
- Implement Data Loss Prevention (DLP)
- Provide user awareness training

---

# Social Engineering

## Overview

Social engineering attacks manipulate users rather than exploiting technical vulnerabilities.

Examples include:

- Fake technical support messages
- QR code scams
- Fraudulent applications
- Smishing
- Voice phishing (Vishing)

### Defensive Controls

- Conduct regular security awareness training
- Verify requests before responding
- Install software only from trusted sources
- Encourage reporting of suspicious communications

---

# Blue Team Detection Opportunities

Security teams should monitor for:

- Unusual application installations
- Unexpected permission changes
- Repeated authentication failures
- Rooted or jailbroken devices
- Device compliance violations
- Malware alerts
- Abnormal battery or CPU usage
- Unexpected outbound network traffic
- Suspicious cloud access activity

---

# Mobile Security Recommendations

Organizations should:

- Deploy Mobile Device Management (MDM)
- Use Mobile Threat Defense (MTD)
- Require Multi-Factor Authentication (MFA)
- Enable device encryption
- Maintain regular software updates
- Monitor mobile endpoints continuously
- Restrict rooted or jailbroken devices
- Provide ongoing security awareness training

---

# CEH Exam Tips

Remember:

- Mobile malware targets smartphones and tablets.
- Smishing is phishing delivered through SMS.
- SIM swapping can bypass SMS-based MFA.
- Rooting and jailbreaking weaken built-in security controls.
- Public Wi-Fi increases the risk of data interception.
- MDM and MTD are important enterprise mobile security controls.
- User awareness remains one of the strongest defenses against mobile threats.

---

# Key Takeaways

- Mobile devices face a wide variety of threats including malware, phishing, insecure wireless networks, SIM swapping, and social engineering.
- A defense-in-depth strategy that includes MDM, MTD, MFA, encryption, regular updates, and user awareness significantly improves mobile security.
- Continuous monitoring and strong enterprise security policies help reduce the likelihood and impact of mobile security incidents.
