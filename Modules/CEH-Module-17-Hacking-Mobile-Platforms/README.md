# CEH Module 17 – Hacking Mobile Platforms

## Overview

This repository contains my study notes, hands-on labs, and TryHackMe write-ups for **Module 17: Hacking Mobile Platforms** from the **EC-Council Certified Ethical Hacker (CEH v13)** curriculum.

The purpose of this module is to understand mobile operating systems, mobile application security, common threats targeting Android and iOS devices, and enterprise mobile security controls. The content is documented from a **defensive cybersecurity** perspective to support learning, exam preparation, and professional development.

---

# Learning Objectives

After completing this module, I will be able to:

- Understand mobile platform architecture
- Learn Android and iOS security models
- Identify common mobile threats and vulnerabilities
- Understand mobile malware and attack vectors
- Learn enterprise mobile security controls
- Study Mobile Device Management (MDM) concepts
- Understand secure mobile application practices
- Map mobile threats to the MITRE ATT&CK Framework
- Prepare for CEH examinations and cybersecurity interviews
