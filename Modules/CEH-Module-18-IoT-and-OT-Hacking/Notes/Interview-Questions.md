# Rapid Revision Sheet

Remember these key concepts:

- IoT connects physical devices.
- OT controls physical processes.
- ICS includes SCADA, PLCs, RTUs, DCS, and HMIs.
- The Purdue Model separates enterprise IT and industrial OT.
- MQTT and CoAP are common IoT protocols.
- Defense-in-Depth uses multiple security layers.
- Zero Trust follows the principle: "Never Trust, Always Verify."
- Secure Boot protects device startup.
- PKI manages digital identities.
- Encryption protects data at rest and in transit.
- Network segmentation limits lateral movement.
- Industrial firewalls protect OT networks.
- IDS detects attacks; IPS can block them.
- SIEM centralizes monitoring and event correlation.
- MITRE ATT&CK for ICS helps defenders understand adversary behavior.

# Interview Tips

For technical interviews:

- Clearly explain the difference between IT and OT.
- Understand the purpose of SCADA, PLCs, RTUs, DCS, and HMIs.
- Demonstrate knowledge of IoT security challenges.
- Be able to discuss Defense-in-Depth and Zero Trust.
- Explain why availability and safety are priorities in OT environments.
- Show familiarity with SIEM, IDS/IPS, and MITRE ATT&CK for ICS.
- Use practical examples when discussing industrial cybersecurity scenarios.
