# Module 19 – Cloud Computing

## Overview

Cloud Computing enables organizations to deliver computing resources such as servers, storage, databases, networking, software, and security services over the Internet. It provides on-demand access to scalable resources without requiring organizations to own or maintain physical infrastructure.

Cloud technologies have become the foundation of modern IT environments and are widely adopted by businesses, governments, and educational institutions. As cloud adoption grows, understanding cloud architecture, security, threats, and defensive strategies has become an essential skill for cybersecurity professionals.

This module introduces the fundamentals of cloud computing, cloud service models, deployment models, virtualization, cloud architecture, cloud threats, cloud security controls, and best practices for protecting cloud environments.

After completing this module, you should be able to:

- Understand cloud security principles and defensive controls.
- Explain the Shared Responsibility Model.
- Understand Identity and Access Management (IAM).
- Apply Defense-in-Depth and Zero Trust in cloud environments.
- Understand cloud monitoring, logging, and incident response.
- Relate cloud security concepts to SOC and Blue Team operations.
