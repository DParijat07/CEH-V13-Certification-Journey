# CEH Module 20 – Cryptography

## Overview

Cryptography is the science of protecting information by transforming readable data into an unreadable format using mathematical algorithms. It is one of the core pillars of cybersecurity and is used to ensure confidentiality, integrity, authentication, and non-repudiation.

Modern organizations rely on cryptography to secure communications, protect sensitive information, authenticate users, secure financial transactions, and maintain trust across digital systems.

This module introduces the principles of cryptography, encryption algorithms, hashing, digital signatures, Public Key Infrastructure (PKI), certificates, SSL/TLS, cryptographic attacks, and defensive best practices.

---

# Learning Objectives

After completing this module, you should be able to:

- Explain the purpose and goals of cryptography.
- Differentiate between encryption, hashing, encoding, and obfuscation.
- Understand symmetric and asymmetric encryption.
- Describe common encryption algorithms such as AES, RSA, ECC, and Diffie-Hellman.
- Explain hash functions and their security properties.
- Understand digital signatures and Public Key Infrastructure (PKI).
- Describe SSL/TLS and HTTPS.
- Identify common cryptographic attacks.
- Implement cryptographic best practices.
- Apply cryptographic concepts during penetration testing and security assessments.
