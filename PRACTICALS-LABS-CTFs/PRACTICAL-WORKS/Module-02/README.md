# Module 02 — Footprinting and Reconnaissance

This directory contains practical exercises related to **Footprinting and Reconnaissance** from CEH v13.

The focus is on learning how to collect, analyze, and document information about a target within an authorized security assessment.

## Practical Areas

* Passive reconnaissance
* Active reconnaissance
* Open-source intelligence (OSINT)
* Domain and DNS information gathering
* WHOIS and domain research
* Website technology identification
* Search engine reconnaissance
* Email and publicly available information analysis
* Network and organizational footprinting
* Reconnaissance findings documentation

## Practical Workflow

**Define Scope → Select Sources → Collect Information → Analyze Results → Validate Findings → Document Evidence**

## Tools

Tools may include:

* WHOIS
* nslookup
* dig
* theHarvester
* Maltego Community Edition, where available
* Browser developer tools
* Public search engines and OSINT resources

Tool selection depends on the exercise objectives and available environment.

## Evidence and Documentation

Each practical exercise should document, where applicable:

* Objective and authorized scope
* Target or lab environment
* Tools and commands used
* Information collected
* Relevant screenshots and outputs
* Observations and limitations
* Potential security implications
* Lessons learned

## Authorization and Safety

Passive reconnaissance should respect privacy, applicable laws, and the terms of the information sources used. Active reconnaissance must be performed only against systems for which explicit authorization has been obtained.

## Learning Outcome

The objective is to develop the ability to collect and analyze relevant target information systematically, understand how reconnaissance supports security assessments, and document findings clearly.
