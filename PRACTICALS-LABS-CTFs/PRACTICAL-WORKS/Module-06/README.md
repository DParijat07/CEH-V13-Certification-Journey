# Module 06 — System Hacking

This directory contains practical exercises related to **System Hacking** from CEH v13.

The focus is on understanding system access security, authentication weaknesses, privilege management, persistence mechanisms, and defensive techniques through controlled, authorized lab exercises.

## Practical Areas

- Password security and authentication
- Password hash analysis
- Authentication security testing
- Privilege escalation concepts
- Windows and Linux access controls
- User and permission management
- System hardening
- Persistence mechanism analysis
- Log analysis and security monitoring
- System compromise indicators
- Security remediation and verification

## Tools and Resources

Tools may include:

- Kali Linux
- Windows and Linux virtual machines
- John the Ripper
- Hashcat
- Windows Event Viewer
- Linux authentication and system logs
- Sysinternals utilities
- Linux command-line security tools

Tool selection depends on the exercise objectives and available lab environment.

## Practical Workflow

**Prepare Lab → Identify Security Controls → Perform Authorized Testing → Observe System Behavior → Analyze Findings → Apply Remediation → Verify Results**

## Evidence and Documentation

Each exercise should document, where applicable:

- Objective and authorized scope
- Operating system and lab configuration
- Tools and commands used
- Relevant outputs and screenshots
- Authentication or access-control observations
- Security weaknesses identified
- Potential impact
- Remediation recommendations
- Verification results and lessons learned

## Authorization and Safety

All exercises must be conducted on personally controlled virtual machines, intentionally vulnerable systems, or explicitly authorized training environments. Persistence and privilege-escalation testing must remain within the approved lab scope.

## Learning Outcome

The objective is to understand how system-level security weaknesses arise, how access controls and authentication can be assessed, and how defensive measures can reduce the risk of unauthorized access.
