# Module 12 — Evading IDS, Firewalls, and Honeypots

This directory contains practical exercises related to **Evading IDS, Firewalls, and Honeypots** from CEH v13.

The focus is on understanding network security controls, evaluating detection and filtering behavior, analyzing security alerts, and learning how defensive systems can be strengthened through authorized lab exercises.

## Practical Areas

- IDS and IPS fundamentals
- Firewall rules and packet filtering
- Network traffic inspection
- Detection signatures and alert analysis
- Packet fragmentation concepts
- Traffic normalization
- Firewall rule validation
- Honeypot fundamentals
- Security control effectiveness
- Detection and prevention improvements

## Practical Workflow

**Prepare Lab → Configure Security Controls → Generate Authorized Test Traffic → Observe Detection → Analyze Alerts → Validate Rules → Improve Controls → Document Results**

## Evidence and Documentation

Each exercise should document, where applicable:

- Objective and authorized scope
- Lab topology and security configuration
- Tools and rules used
- Test traffic and observed behavior
- IDS/IPS alerts and relevant logs
- Firewall filtering results
- Detection gaps and limitations
- Recommended configuration improvements
- Retest results and lessons learned

## Authorization and Safety

All exercises must remain within controlled lab environments or explicitly authorized assessment scopes. Do not attempt to bypass security controls protecting systems or networks without permission. Avoid testing techniques that could disrupt production services.

## Learning Outcome

The objective is to understand how network security controls inspect and filter traffic, interpret detection alerts, identify defensive gaps, and improve monitoring and prevention mechanisms.
