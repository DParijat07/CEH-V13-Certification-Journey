Module 03 — Scanning Networks

This directory contains practical exercises related to Scanning Networks from CEH v13.

The focus is on discovering hosts, identifying open ports, detecting running services, and understanding how network scanning supports vulnerability assessment and security analysis.

Practical Areas

- Host discovery
- Network discovery and mapping
- TCP port scanning
- UDP port scanning
- Service and version detection
- Operating system detection
- Scan result analysis
- Firewall and filtering behavior
- Network scanning documentation

Tools

Tools may include:

- Nmap
- Wireshark
- Netcat
- ping
- traceroute or tracert

Tool selection depends on the exercise objectives and lab environment.

Practical Workflow

Define Scope → Identify Hosts → Scan Ports → Detect Services → Analyze Results → Validate Findings → Document Evidence

Evidence and Documentation

Each practical exercise should include, where applicable:

- Objective and authorized target scope
- Lab environment and network configuration
- Tools and commands used
- Scan results and relevant screenshots
- Open ports and detected services
- Observations and potential security implications
- Limitations and lessons learned

Authorization and Safety

All scanning activities must be restricted to personally controlled lab systems, intentionally vulnerable machines, or explicitly authorized targets. Scanning public or third-party systems without permission is outside the scope of this repository.

Learning Outcome

The objective is to develop practical skills in network discovery, port scanning, service identification, scan-result interpretation, and technical documentation.
