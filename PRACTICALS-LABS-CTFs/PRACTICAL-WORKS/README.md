# Practical Works

This directory contains individual hands-on exercises completed during my **CEH v13 learning journey**.

The focus is on practicing specific cybersecurity **tools, commands, techniques, and methodologies** in controlled and authorized environments.

## Objectives

* Convert CEH concepts into practical skills
* Practice commonly used cybersecurity tools
* Understand how security techniques work in practice
* Develop systematic problem-solving skills
* Record practical observations and results
* Build evidence of hands-on learning

## Practical Work Format

Each practical exercise will be organized as an individual directory containing relevant documentation and evidence.

```text

│

    ├── README.md
    └── Evidence/
```

For larger practical exercises, additional documentation may be included when required.

## Typical Workflow

**Objective → Environment → Tool/Technique → Execution → Observation → Analysis → Evidence → Learning**

## Scope

Practical exercises may cover areas such as:

* Information Gathering
* Reconnaissance
* Network Scanning
* Enumeration
* Vulnerability Analysis
* System Security
* Password Security
* Sniffing and Traffic Analysis
* Web Security
* SQL Injection
* Wireless Security
* Cloud Security
* IoT/OT Security
* Cryptography
* Defensive Security Techniques

## Authorization

All practical activities are performed only against:

* Personally controlled lab environments
* Intentionally vulnerable machines
* Authorized training environments
* Legally provided cybersecurity practice platforms

No unauthorized systems or real-world targets are tested.

## Purpose

These practical works are maintained as **proof of hands-on learning** and as a reference for future cybersecurity projects, interviews, and professional development.
