# CEH V13 — Practicals, Labs & CTFs

This directory contains the **hands-on practical work, cybersecurity labs, and CTF activities** completed during my CEH v13 learning journey.

The purpose of this section is to demonstrate the practical application of concepts learned from the CEH modules through **tools, techniques, lab environments, real-world scenarios, and security challenges**.

---

## Directory Structure

```text
PRACTICALS-LABS-CTFs/
│
├── PRACTICAL-WORKS/
├── LABS/
└── CTFs/
```

### PRACTICAL-WORKS

Contains individual hands-on exercises focused on learning and practicing specific cybersecurity tools, commands, techniques, and attack methodologies.

Examples:

* Reconnaissance
* Network scanning
* Enumeration
* Vulnerability identification
* Web application testing
* Password/security testing
* Traffic analysis
* Cryptography exercises

---

### LABS

Contains structured, scenario-based cybersecurity labs performed in controlled environments.

Each lab may include:

* Lab objective
* Environment/setup
* Attack or testing methodology
* Tools used
* Observations
* Evidence
* Findings
* Remediation or mitigation
* Lessons learned

---

### CTFs

Contains Capture The Flag challenges completed as part of practical cybersecurity learning.

CTF activities may include platforms such as:

* TryHackMe
* Hack The Box
* Other legal and authorized CTF platforms

Each CTF write-up focuses on the **methodology, enumeration, exploitation, analysis, and lessons learned** rather than simply documenting the final flag.

## Practical Philosophy

The objective is not only to learn **what a technique is**, but to understand:

**Understand → Configure → Execute → Observe → Analyze → Document → Improve**

All activities are performed in **authorized and controlled environments** such as personal virtual machines, intentionally vulnerable systems, training platforms, and legally provided CTF environments.

---

## Evidence & Documentation

Where appropriate, practical activities include supporting evidence such as:

* Screenshots
* Command output
* Tool results
* Network observations
* Findings
* Lab notes
* Remediation recommendations

Sensitive information, credentials, personal data, and unauthorized targets are excluded from the repository.
